### 2026-09-29 · 新增 [[B04-multi-skill]]（skill 子命令扩展方案：多 skill install / list / `--group`）

这一条是**创建时一次定的设计选择**——与 B01/B02/B03 不在同一性质层。

放 B 组的原因：用户指定 B04 编号（按 key-board 当下 ref 编号习惯），
